# README demo cards

Static SVG snapshots used by [`readme.md`](../../readme.md) so documentation images keep rendering after the public `github-readme-stats.vercel.app` instance was shut down (see [#4671](https://github.com/anuraghazra/github-readme-stats/issues/4671)).

These files are illustrative only. For your own profile, generate cards with the [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action) or a [self-hosted](../../readme.md#self-hosted-vercelother-recommended) instance.
